Scenario & scope

Cedar Desk needs an action list for its homepage, organizer collection, bamboo tray product, small-desk guide, and comparison guide. These findings are fictional examples based on a made-up page inventory. No live crawl, traffic analysis, or Core Web Vitals measurement was performed.

The review covers content clarity, page titles, headings, and internal links. Priorities reflect the likely effect on usability and task completion in this scenario; they are not Google ranking scores.

The draft describes the page without inventing product specifications. The catalog owner must supply those facts.

What comes next

  1. Confirm the reported problems against the real site and document exact URLs and evidence.
  2. Fix the broken internal destination first, then review titles and missing product facts.
  3. Check the mobile layout, heading structure, descriptive links, and image context after edits.
  4. Use authorized Search Console access for indexing checks and a PageSpeed tool for actual performance data.
  5. Track comparable periods and business-relevant conversions. Annotate changes without attributing every traffic shift to a single fix.

Handoff format

Each task includes a URL, finding, evidence, priority rationale, proposed fix, owner, status, and validation result. Mark a task complete only after the page has been reviewed following the change.
