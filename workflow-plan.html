SUPPORTING SKILL / PRACTICE PLAN

A support-request review workflow

A small no-code exercise to build after gaining hands-on platform experience. This page is a specification and test plan, not a deployed automation.

The proposed workflow

  1. Receive

    A form collects request ID, email, order number and question.

  2. Validate

    Missing details go to a clarification list. A repeated request ID stops before adding another row.

  3. Prepare

    Look up the approved order record and prepare a response draft using a template or an optional AI step.

  4. Review

    A person checks facts and policy before sending from the approved support channel.

Practice checklist

Test inputExpected handling
Complete shipping questionOne row, matching order details, draft awaiting review.
Same request ID twiceOne queue entry; second request recorded as duplicate.
Missing order numberClarification required; no guessed order match.
Refund requestOwner approval required; no automatic refund.
Unknown order numberManual review; do not fabricate an order.
App connection failsRetain the request and flag retry; no automatic customer send.

Proposed learning tools: Google Forms or Gmail, Google Sheets, and one of Zapier, Make or n8n. Choose one platform and verify its available modules during setup.

Completion evidence would include an actual workflow screenshot, test records and a recorded walkthrough. These have not been produced yet, so this is kept separate from the completed file-based samples.
