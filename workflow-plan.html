    WHAT THIS PROJECT SOLVES

    Keep the routine moving.
    Keep judgment with a person.

    Incomplete requests need clarification. Refunds need an owner’s decision. Repeated requests should not create duplicate work. This prototype makes those paths visible and leaves a review trail.

    • Exact order and email match before using order facts.
    • Missing information goes to clarification, without a guessed match.
    • Refunds always route to manual approval.
    • Same ID with different details flags an ID conflict.

    WHERE AI FITS NEXT

    A clear boundary
    for the next version.

    This demo uses rules and response templates; it does not call an AI model or connect to a live store. The next version would use AI to summarize a request and draft from approved order facts, with the same checks and human approval.

    Planned integration: form or inbox → workflow tool → approved order records → AI draft → review queue. Platform setup, credentials, output evaluation, and failure handling still need hands-on validation.
